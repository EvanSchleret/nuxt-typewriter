# Security Policy

## Supported Versions

Security updates are provided for the latest released version of `@evanschleret/nuxt-typewriter`.

## Reporting a Vulnerability

Please report vulnerabilities privately through [GitHub Private Vulnerability Reporting](https://github.com/EvanSchleret/nuxt-typewriter/security/advisories/new).

Do not disclose the vulnerability publicly before it has been reviewed. Include the affected version, a description of the impact, and steps to reproduce when safe to do so.

Evan Schleret will acknowledge reports as soon as possible and coordinate a fix and disclosure timeline with the reporter.
