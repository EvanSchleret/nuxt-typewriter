# Contributing to nuxt-typewriter

Thank you for contributing to `@evanschleret/nuxt-typewriter`.

## Prerequisites

- Bun 1.3 or newer
- Node.js compatible with the supported Nuxt version

## Local setup

```bash
bun install
```

## Development commands

```bash
bun run lint
bun run typecheck
bun run test
```

Do not run an application build to test the package. Use the playground and the package test suite instead.

## Pull requests

- Keep changes focused and consistent with the existing module structure.
- Add or update tests when behavior changes.
- Update documentation for user-facing changes.
- Explain breaking changes and migration steps in the pull request description.

Please open an issue first for larger changes so the scope can be discussed before implementation.
